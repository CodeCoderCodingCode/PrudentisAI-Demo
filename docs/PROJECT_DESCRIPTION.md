# Project descriptions

## GitHub About — English

AI-assisted personal finance demo built with Next.js, React and PostgreSQL. Track accounts, transactions and budgets, explore spending charts, scan receipts and automate monthly reports. Hosted demo on request.

## GitHub About — Deutsch

Fullstack-Demo für persönliche Finanzen mit Next.js, React und PostgreSQL: Konten, Buchungen, Budgets, Ausgabenanalysen, KI-Belegscan und automatisierte Monatsberichte. Gehostete Demo auf Anfrage.

## Portfolio description — Deutsch

Prudentis AI macht aus einzelnen Buchungen einen verständlichen Blick auf die eigenen Finanzen. Die Fullstack-Anwendung bündelt Giro- und Sparkonten, Einnahmen, Ausgaben und ein Monatsbudget in einer interaktiven Oberfläche. Diagramme zeigen, welche Kategorien das Budget prägen und wie sich Einnahmen und Ausgaben im Zeitverlauf entwickeln.

Technisch verbindet das Projekt Next.js und React mit Prisma und PostgreSQL. Clerk übernimmt die Anmeldung, Arcjet ergänzt den Schutz von Anfragen. Die KI-Anbindung ist für das Auslesen von Belegen und monatliche Berichtshinweise vorgesehen; Inngest und Resend übernehmen Hintergrundabläufe und E-Mail-Berichte. Ein konfigurierbares Modell und begrenzte Scan-Versuche ermöglichen einen kontrollierten Einstieg mit dem Gemini-Free-Tarif.

Das Repository enthält echte Browseraufnahmen der originalen Komponenten, eine unabhängig startbare lokale Vorschau und nachvollziehbare Einrichtungs- und Architekturhinweise. Die gehostete Demo wird auf Anfrage aktiviert. Externe Integrationen benötigen eigene Zugangsdaten; ein erfolgreicher Live-Test mit diesen Diensten wird nicht vorausgesetzt oder behauptet.
